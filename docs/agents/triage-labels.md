# Triage Labels — Data-Pro-Skill

Maps the five canonical triage roles to the label strings in `pablodiegoo/Data-Pro-Skill`.

| Canonical role | Label in this repo | Notes |
| :--- | :--- | :--- |
| `needs-triage` | `needs-triage` | Applied to new issues awaiting maintainer review |
| `needs-info` | `needs-reproduction` | Waiting on reporter — dataset sample or reproduction steps required |
| `ready-for-agent` | `confirmed` | Bug verified and reproducible — ready for implementation |
| `ready-for-human` | `enhancement` / `feature` | Enhancement or new methodology/design school approved for development |
| `wontfix` | `wontfix` | Out of scope or violates the 8-Article Data Constitution |
