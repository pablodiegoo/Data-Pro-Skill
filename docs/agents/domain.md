# Domain Docs — Data-Pro-Skill v2.0

How engineering and analytical skills consume this repository's domain documentation.

## Layout

```
/
├── GLOSSARY.md         ← Canonical Leading Words (Leitworte) domain & statistical vocabulary
├── constitution.md     ← Non-negotiable 8-Article statistical, qualitative & visual constitution
├── CONTEXT.md          ← Architectural context, history, and design decisions
└── references/         ← Progressive disclosure command & survey science specifications
```

## Before exploring or editing, read these

1. **`GLOSSARY.md`** at the repo root — canonical terms for every deliverable, statistical test, survey science methodology, and Tufte HTML component.
2. **`constitution.md`** — the 8 Articles governing precision (`±MoE%`), effect sizes, parametric/non-parametric pairing, small-sample discipline ($N < 30$), quality gates, survey governance, and Tufte print-ready HTML output.
3. **`CONTEXT.md`** — architectural overview and multi-agent design principles.

## Use the glossary's vocabulary

When naming variables, writing prompts, designing Python functions, or formatting reports, use the exact **Leading Words** defined in `GLOSSARY.md`. Do not drift to informal synonyms.
